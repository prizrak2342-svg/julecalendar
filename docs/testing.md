# Тестування

## Що буду перевіряти

| ID | Що | Як має бути |
| --- | --- | --- |
| T01 | Запуск | `npm ci` і `npm start` працюють, база підключається, всі сторінки відкриваються |
| T02 | Стилі й картинки | CSS і зображення вантажаться |
| T03 | Дата відкриття | До 00:00 віконце закрите, після відкрите. Майбутнє віконце не відкривається навіть через пряме посилання |
| T04 | Неправильний день | `/calendar/0`, `/calendar/25`, `/calendar/abc` дають 404 |
| T05 | Вміст | Текст, картинки (з alt), відео і запитання показуються |
| T06 | Відповіді | Нормальна відповідь зберігається, порожня або задовга ні, друга на те саме віконце ні |
| T07 | Доступ | Без входу або під учнем адмінка не відкривається |
| T08 | Перевірка відповідей | Позначка правильно/неправильно зберігається разом з тим, хто перевіряв |
| T09 | Жеребкування | Виграти може тільки правильна відповідь. Без правильних відповідей буде зрозуміле повідомлення. Повторне жеребкування не міняє переможця |
| T10 | Минулі віконця | Видно ім'я переможця, e-mail ніде не світиться |
| T11 | База | Дані не зникають після перезапуску, дублікатів немає |
| T12 | Зручність | Працює з клавіатури, видно фокус, є підписи полів, нормальний контраст, добре виглядає на телефоні |
| T13 | Безпека | EJS екранує текст, форми захищені від CSRF, секретів немає в Git |
| T14 | SSH | Я і всі вчителі заходимо на сервер своїми ключами |
| T15 | Сервер | Сайт працює через nginx, pm2 піднімає застосунок, після перезавантаження VM усе працює |
| T16 | Бекап | `mongodump` і `mongorestore` працюють |
